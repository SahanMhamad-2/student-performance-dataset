# student-performance-dataset

INTRODUCTION
This dataset is designed to track and analyze the various factors that influence academic success among students. It combines demographic details, socioeconomic backgrounds, institutional environments, and individual learning habits to provide a holistic view of a student's educational journey.

By capturing key metrics—such as attendance rates, weekly study hours, parental education, family income, and prior academic achievements—the dataset serves as a valuable resource for identifying the core drivers of student success and building predictive models for future performance.
